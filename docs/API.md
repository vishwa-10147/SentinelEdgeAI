# SentinelEdgeAI API reference

Generated by `scripts/gen_api_reference.py` from the running route table; the minimum role of every endpoint is enforced and tested in `tests/test_endpoint_roles.py`.

Authentication: `Authorization: Bearer <console access token | sak1 API token>` or `X-API-Key: <key>`. Roles: Viewer < Analyst < Operator < Admin. All responses carry the security headers described in SECURITY.md. Rate limits: 600 reads and 60 writes per client per minute.
